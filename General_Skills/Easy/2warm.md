**Category:** General Skills | **Difficulty:** Easy | **Author:** Sanjay C/Danny Tunitis

## Challenge Description
*"Can you convert the number 42 (base 10) to binary (base 2)?"*

This challenge tests basic knowledge of positional numeral systems, specifically converting integers from Decimal (base 10) to Binary (base 2).

___

## Analysis
- **Decimal (Base 10):** The standard numeral system using digits `0-9`.
- **Binary (Base 2):** using bits `0` and `1`.
