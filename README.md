# Cybersecurity Journey & Writeups

Welcome to my technical portfolio. This repository documents my progression through various cybersecurity challenges, demonstrating practical problem-solving skills and an evolving understanding of security fundamentals.

## Objective
This project serves as a living document of my technical capabilities. My primary goal is to build a robust foundation in offensive security concepts, aiming for a role as a Junior Penetration Tester / Red Team Trainee.

## Technical Proficiencies Developed
Through consistent practice, I am honing my skills in several core domains:

* **Linux / Command Line Operations:** Advanced data parsing (grep, find, awk), file permissions, and system navigation.
* **Network Forensics:** Packet capture analysis, HTTP/TCP stream filtering, and payload extraction using Wireshark and tshark.
* **Programming / Scripting:** Debugging Python syntax, command-line argument parsing, and automating extraction processes.
* **Cryptography & Binary Exploitation:** Base64/Hex encoding, metadata extraction, and binary inspection.

## Methodology
I approach every challenge with a consultant mindset. My writeups are structured as follows:
1. **Initial Reconnaissance:** Analyzing the provided artifacts and enumerating the attack surface.
2. **Execution:** Step-by-step exploitation using standard industry tools.
3. **Key Takeaways:** Extracting underlying security principles to apply them to real-world scenarios.
